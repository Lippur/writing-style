# Word swaps

Plain words for words that STE does not approve or that make prose heavy. The list is a short working list. It is not the ASD-STE100 dictionary.

- 80% mode: use the swap if it reads naturally. Keep the original word if the swap sounds odd or changes the meaning.
- Strict mode: use the swap. If a word-for-word swap breaks the sentence, rebuild the sentence.
- Many words have more than one swap. Pick by context.

## Verbs of doing

| Instead of | Write |
|---|---|
| accomplish | do, complete |
| carry out, conduct, perform | do |
| execute (a task) | do (keep "execute" for code if it is the term of the field) |
| implement (a plan) | do, apply |
| utilise, leverage, employ | use |
| facilitate | help, let |
| assist | help |
| attempt | try |
| repeat | do again |

## Verbs of seeing, showing and finding

| Instead of | Write |
|---|---|
| verify, ensure, confirm | make sure |
| check (as a verb) | make sure, examine, measure (strict); as a noun: "do a check" |
| inspect | examine |
| observe | monitor, see |
| indicate, demonstrate | show |
| locate, determine | find |
| identify | find, know |

## Verbs of getting and giving

| Instead of | Write |
|---|---|
| obtain, acquire, achieve, reach, receive | get |
| provide, supply | give |
| allow, permit, enable | let |
| require | need (80%), make necessary (strict) |

## Modal verbs

| Instead of | Write |
|---|---|
| shall, should (obligation) | must |
| should (advice) | we recommend that you ..., or the imperative |
| may (permission) | can |
| may, might, could (possibility) | can, possibly |
| would | will, or rewrite in the present tense |

Keep the strength of the original. Do not turn "might" into a certain statement.

## Typical LLM vocabulary

These words are not STE words, and they make text read as machine writing. Remove them or use the plain form.

| Instead of | Write |
|---|---|
| delve into, dive into | examine, read about |
| robust | strong, reliable |
| seamless, seamlessly | (delete), or say what works without a problem |
| comprehensive | full, complete |
| crucial, pivotal, vital | important, necessary |
| landscape, realm | field, area |
| showcase, underscore, highlight | show |
| streamline | simplify |
| empower | let, help |
| harness | use |
| foster | help, cause |
| navigate (a problem) | solve, handle |
| a testament to | shows |
| game-changer | (delete), or give the result |
| unlock | let, give |
| tapestry, journey | (delete) |
| genuinely, truly, really (as an amplifier) | (delete) |
